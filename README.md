# Gym member segmentation

Clusters 330 gym members with k-means (k = 4) and compares giving every member a $10 monthly extras credit with giving that credit only to New light users. The analysis reads `gym_members (1).csv` and saves `elbow_plot.png`.

## Installation

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Run

```bash
python analysis.py
```
